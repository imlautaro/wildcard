Features are implemented in the API and exposed on **both** iOS and web with matching behavior, unless a platform limitation prevents it. Each feature has a detailed guide in the [Reference](/en/reference/overview), maintained in `docs/` with its API contract, migrations, cache rules, verification status and rollback notes.

## Verification status

The guides are explicit about what has and has not been verified (for example "device behavior not verified" or "live inference pending"). This documentation does not upgrade those statements: if a guide says something is unverified, treat it as unverified.
