## Contact memory

[`docs/memory.md`](/en/reference/memory). Inside `ChatWorkflow`, facts are extracted in batches and stored as grounded memories (migrations 0007, 0019, 0030). Before each reply the API selects bounded recent context and relevant memories; contacts also have private tools to search memories and message history (FTS5). Each agent keeps its own stated persona and preferences across chats and can retrieve attributed statements from common group members through bounded, permission-checked search.

- **Audience scoping**: memories are stored per audience, so what a contact learns in one chat only appears where the privacy rules allow it.
- **Conversation-local memory**: chats and groups with MCP connectors keep memory local and are permanently excluded from cross-chat memory.
- **Semantic ranking (optional)**: with `SEMANTIC_MEMORY_ENABLED=true`, candidates are re-ranked with Workers AI `@cf/baai/bge-m3` embeddings stored in D1 (0057). Off by default.

## Topic recall

Before a private reply, contacts rank earlier private and group history by topic terms; linked contacts can search groups they share. Group replies are unchanged.

## Conversation learning

[`docs/conversation-learning.md`](/en/reference/conversation-learning). After an exchange (at least three messages, 15-minute cooldown), `ChatWorkflow` runs one silent review and stores one `conversation_learning` row per audience, agent and person (0067): interaction observations, small behavioral adjustments and optional questions. Both clients offer per-person inspection, disable and reset. No new Workflow or Cron.

## Privacy controls

[`docs/privacy.md`](/en/reference/privacy) defines where facts may travel and documents a privacy audit from November 1, 2026. Migration 0093 adds:

- **Keep this chat private**: the chat's facts never leave it.
- **Contacts share with each other**: an account-level switch for `ask_linked_contact` / `tell_linked_contact`.

Shared contacts disclose shared-memory use before acceptance, and group participants grant private-text sharing per person and per group.

::note
Live model adherence to these rules is described as not yet verified in the guides; the enforcement points are in SQL scoping and tool authorization, not only in prompts.
::
