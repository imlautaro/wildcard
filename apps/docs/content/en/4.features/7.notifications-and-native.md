## Push notifications

[`docs/notifications.md`](/en/reference/notifications). Every reply writes an entry in a push outbox (migrations 0004 and 0018). The Workflow attempts immediate delivery and the Cron retries.

| Channel | Implementation | Configuration |
| --- | --- | --- |
| APNs (iOS) | ES256 JWT signed with WebCrypto PKCS#8/P-256, HTTP/2 to `api.push.apple.com` or the sandbox host | `APNS_PRIVATE_KEY`, `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_TOPIC` |
| Web Push (browsers) | RFC 8030/8291/8292 with `aes128gcm` and VAPID, implemented with WebCrypto | `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (migration 0085) |

Alerts show the contact's name, the reply text (plain summary of the Markdown) and the contact's avatar. Without configuration, chats keep working and pending notifications expire. Notifications are suppressed for a chat the person is currently viewing (`chat_visit`, not for groups). Unread counts persist on the server (0005).

## Native experiments (iOS)

[`docs/native-experiments.md`](/en/reference/native-experiments). A private contact can prepare device-specific requests: system timers and alarms, Calendar events and Reminders (including location reminders), recorded in a `native_action` ledger (0031). New timers and alarms run automatically while the requesting iPhone app is open; other tools can be allowed to run without confirmation. iOS permissions still apply, and each execution produces a receipt the contact sees in later turns. Enable per contact or from Account. The web app offers a guide and a contact-link fallback.

## Remote timers and alarms

[`docs/native-remote.md`](/en/reference/native-remote). An iOS or web chat can target an explicitly linked iPhone. The API sends a visible APNs alert and the notification service extension schedules the timer or alarm with AlarmKit, even while the phone is locked; only a device receipt counts as execution (0034). With participant delegation (0083), a person can allow a named participant of a shared contact to request timers on their phone. Requires the App Group and the notification service App ID.
