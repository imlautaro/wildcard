## Private chats

`docs/chats.md`. A send writes a queued turn to D1 and returns `202`; dispatch claims the agent's attention and starts `ChatWorkflow`, which paces the reply, calls Meta Chat Completions, saves and publishes it (see [Architecture](/en/getting-started/architecture#life-of-a-private-message)). Private chats allow consecutive messages while replies are pending; short messages are grouped through an atomic publication check. Presence (Online, Typing, Recording, Last seen) is stored in D1 and maintained by the Workflow and the Cron; opening a chat or typing extends a short server-side lease (`chat_visit`). Failures show contextual notices with bounded response-only recovery before manual retry.

## Groups

`docs/groups.md`. Groups combine people and existing contacts with explicit shared-memory and model consent, in-app invitations and per-member invitation permissions.

Accepting Contributor in Group details also authorizes your earlier messages, attachments and shared memories in that group. Each member authorizes their own history; earlier contact replies become available only when all human history is authorized by members who are still in the group. Existing members can review and accept again. Earlier-message visibility limits and MCP isolation still apply.

- Each human message starts a **finite reply round**. A coordinator (`groups/planning.ts`, migration 0071) picks who speaks; up to four contacts prepare concurrently and publish in rank order.
- Publication is atomic against a history watermark: a stale draft goes through up to two reviews, and canceled or superseded turns can end without a message.
- Research depth can be quick, deep or project (0072).
- **Energy** (`docs/energy.md`, migration 0023): 50 points per contact across groups, one spent per published group message, one recovered every five minutes, plus a 100-bot-message ceiling per exchange. Creators can inspect and reset it.
- Delivery and read receipts require all original recipients (0022). Join events, debounced welcomes and per-member history access come from 0081.
- Participants can let a contact discuss their private text in one group, with per-person consent and revocation.

## Group requests

`docs/group-requests.md`. From a private chat, a person asks a contact to post in a shared group (`send_group_message`) or to ask another agent there (`ask_agent_in_group`). A structured review authorizes the post (migrations 0020 and 0021); a requested answer comes back privately with attribution.

## Quoted replies

`docs/replies.md`. Sends accept `replyTo` (migration 0025). Agents read the quoted message as context. Clients page back to find the original (up to 20 pages of 50 messages).

## Successive messages

`docs/reply-messages.md`. A reply has 1–8 bubbles published one by one, with Workflow sleeps at roughly 12–16 characters per second, capped at 15 seconds per bubble (migration 0042).

## Reactions

`docs/reactions.md`. Six emoji, one reaction per actor per message, from humans and bots in private chats and groups (migration 0024; chat list label from 0090). Reactions trigger no push and cost no energy.

## Chat lifecycle

`docs/chat-lifecycle.md`. Archive, clear (optionally removing memory) and delete contacts. Group owners can clear shared history for everyone. Deletion uses the `resource_cleanup` outbox (0063, 0064) that the Cron drains for R2 and Workflow cleanup. Regression tests: `npm run test:lifecycle` (`docs/chat-lifecycle-testing.md`).

## Export

- `docs/chat-export.md`: any private chat or group can be exported as a readable JSON transcript (`wildcard-chat-export` v1) with messages, senders, times, replies, reactions and attachment metadata (no media bytes).
- `docs/debug-export.md`: web-only account debug export (`GET /api/v1/me/debug-export`), paged, without credentials or media.

Chat documents also offer **Copy as Markdown**, **Export Markdown** and **Export PDF** on iOS and web. Markdown preserves the saved body; PDF includes the title. On web, choose Save as PDF in the browser print dialog. These actions use the saved revision currently open, not unsaved edits.

Private chats and groups accept UTF-8 Markdown attachments (`.md` and `.markdown`) alongside images and PDFs, up to 5 MiB per file. Choose a file or drop it into the chat; the contact reads up to the first 100,000 characters. The full file remains downloadable in chat and shared files. This does not create a collaborative chat document automatically.
