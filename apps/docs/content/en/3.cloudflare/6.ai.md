## The `AI` binding

```jsonc [apps/api/wrangler.jsonc]
"ai": { "binding": "AI" }
```

It serves two purposes:

1. **Workers AI embeddings** for optional semantic memory.
2. **AI Gateway transport** for Meta model calls when routing is enabled.

Text generation itself does **not** use Workers AI models: replies come from Meta's Muse Spark 1.3 through the Meta Model API.

## Semantic memory (optional)

With `SEMANTIC_MEMORY_ENABLED="true"`, memory selection re-ranks lexical candidates with `@cf/baai/bge-m3` embeddings (`apps/api/src/chat/semantic-memory.ts`). Vectors are stored in D1 (migration 0057) rather than Vectorize, keeping isolation rules in SQL. The flag ships as `"false"`. Locally it still calls the remote Workers AI service.

## AI Gateway

The gateway is **observability only**: estimated Spark spend and request metadata in the Cloudflare dashboard. No fallback, caching, retries, prompt logging or guardrails are configured.

```ts [apps/api/src/chat/meta.ts (simplified)]
if (env.AI_GATEWAY_ID) {
  // Authenticated by the binding; the provider key is still META_API_KEY.
  return env.AI.gateway(env.AI_GATEWAY_ID).run({ provider: 'custom-meta', /* … */ });
}
return fetch('https://api.meta.ai/v1/chat/completions', /* … */);
```

| Setting | Value |
| --- | --- |
| Gateway | `wildcard`, authenticated |
| Custom provider | `meta`, base URL `https://api.meta.ai` |
| Payload logs, cache, retries, rate limits | Off by default; per-request headers enable metadata-only logs and custom costs |
| Current state | `AI_GATEWAY_ID=""` (direct calls) since production returned HTTP 502 through the gateway on October 27, 2026 |

Voice transcription and web research always call Meta directly and are excluded from gateway metrics.

### Provisioning the gateway

```bash [Terminal]
npm run infra:ai-gateway            # verify
npm run infra:ai-gateway -- --create  # create gateway and provider if missing
```

The script uses your Wrangler login in memory or an explicit `CLOUDFLARE_API_TOKEN` with AI Gateway read and edit permissions. It never prints tokens, overwrites an existing provider or deploys. To re-enable routing, set `AI_GATEWAY_ID` in `apps/api/wrangler.jsonc`, commit and push, then verify a fictional-data request end to end.

## Meta Model API usage

| Model | Endpoint | Used for |
| --- | --- | --- |
| `muse-spark-1.3` / `muse-spark-1.3-contributor` | `/v1/chat/completions` | Replies, tools, memory extraction, planning, reviews |
| Muse Spark with `web_search` | `/v1/responses` (`store: false`) | Web research |
| `muse-image-1.0` | `/v1/images/generations`, `/v1/images/edits` | Portraits, chat images, albums, sticker art |
| `muse-voice-transcribe-1.0` | `/v1/asr/transcribe` | Voice message transcription |
| `sam-3.1` | `/v1/responses` (streamed, parsed with `@meta-sam/parser`) | Sticker cutouts |

Completions are non-streaming with a 45-second timeout and a 256 KB response cap. Each account chooses **Standard** or **Contributor** (with explicit consent); chats with MCP connectors always use Standard.
