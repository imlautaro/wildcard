## Local development

::accordion
  :::accordion-item{label="Sending a message returns 503" icon="i-lucide-circle-alert"}
  `META_API_KEY` is missing from `apps/api/.dev.vars`. Auth and contacts work without it; replies need it. Restart `wrangler dev` after editing `.dev.vars`.
  :::

  :::accordion-item{label="Auth fails with a secret error" icon="i-lucide-circle-alert"}
  `BETTER_AUTH_SECRET` is missing or shorter than 32 characters. Run `npm run auth:setup:local` (it does not overwrite an existing file; delete a broken one first).
  :::

  :::accordion-item{label="SQL errors about missing tables or columns" icon="i-lucide-circle-alert"}
  Your local D1 is behind. Run `npm run db:migrate:local`.
  :::

  :::accordion-item{label="The admin panel shows 404 or 'Not a super admin'" icon="i-lucide-circle-alert"}
  Set `ADMIN_LOCAL_ROUTES=true` and your local user ID in `SUPER_ADMIN_USER_IDS` in `.dev.vars`, then restart the API.
  :::

  :::accordion-item{label="Types are out of date after editing wrangler.jsonc" icon="i-lucide-circle-alert"}
  Run `npm run types --workspace @wildcard/api` (or `npm run typecheck`, which includes it).
  :::

  :::accordion-item{label="vue-tsc fails to load TypeScript" icon="i-lucide-circle-alert"}
  The Nuxt apps type-check with the aliased `typescript6` package through their `scripts/typecheck.mjs`. Run the npm script instead of calling `vue-tsc` directly.
  :::

  :::accordion-item{label="MCP OAuth does not work locally" icon="i-lucide-circle-alert"}
  OAuth requires public HTTPS origins for the API and the web app. Use public or Bearer connections locally.
  :::

  :::accordion-item{label="The web app crashes at startup after adding a composable" icon="i-lucide-circle-alert"}
  Check for an import cycle through `useSession`. It must not import other composables.
  :::
::

## Production

::accordion
  :::accordion-item{label="A Workers Builds release refuses to run" icon="i-lucide-circle-alert"}
  Read the guard message: it must run in Workers Builds, on the production branch, with a clean checkout and `HEAD` equal to `WORKERS_CI_COMMIT_SHA`. The first build after connecting a repository may lack metadata; push another commit. Do not bypass the guard with a manual deploy.
  :::

  :::accordion-item{label="The API release stops about META_API_KEY" icon="i-lucide-circle-alert"}
  The build secret is empty, or absent both in the build and at runtime. Set the encrypted build variable and push again.
  :::

  :::accordion-item{label="The admin build fails after an API change" icon="i-lucide-circle-alert"}
  The admin binding may reference an `AdminAPI` change that the API has not released yet. Retry the admin build after `wildcard-api` succeeds.
  :::

  :::accordion-item{label="Replies fail with HTTP 502 through the AI Gateway" icon="i-lucide-circle-alert"}
  This happened on October 27, 2026. Clear `AI_GATEWAY_ID` (direct calls) and push; investigate the gateway separately.
  :::

  :::accordion-item{label="Everyone was signed out" icon="i-lucide-circle-alert"}
  `BETTER_AUTH_SECRET` changed (rotation, or the Worker was deleted and recreated). Sessions and encrypted MCP credentials from the old secret are no longer valid.
  :::

  :::accordion-item{label="No push notifications arrive" icon="i-lucide-circle-alert"}
  Check that all four `APNS_*` (or all three `VAPID_*`) build secrets are set and released, that `APNS_TOPIC` matches the bundle ID and that the app's `APNS_ENVIRONMENT` matches the signing. Look for `push_accepted`, `push_provider_signing_failed` or `push_delivery_deferred` events in Workers Logs.
  :::

  :::accordion-item{label="A turn is stuck in Typing" icon="i-lucide-circle-alert"}
  The minute Cron's `recoverChats` reconciles turns with their Workflow status. Check the Workflow instance in the dashboard (`chat-<turnID>-a1`) and Workers Logs for model errors.
  :::
::

## Where to look

- **Workers Logs and traces** in the Cloudflare dashboard for each Worker (sanitized events only).
- **Workflows** dashboard for instance status and step history.
- **Workers Builds** logs for build and release output.
- The feature guide in `docs/` for known limitations and pending verification.
