This site is the workspace `@wildcard/docs` in `apps/docs`, built with [Docus](https://docus.dev) 5 (a Nuxt layer over Nuxt Content, Nuxt UI and Tailwind CSS 4).

## Structure

```text
apps/docs/
├── app/
│   ├── app.config.ts     # Header, colors, navigation, SEO defaults
│   └── app.css           # Wildcard brand color scale and Manrope
├── content/
│   ├── en/               # English pages
│   └── es/               # Spanish pages (identical tree)
├── public/               # favicon, fonts, _redirects
├── nuxt.config.ts        # extends docus, i18n (en, es), static preset
├── wrangler.jsonc        # assets-only Worker wildcard-docs
└── package.json
```

Top-level folders in `content/<locale>/` become the header tabs; numeric prefixes (`1.getting-started`) set the order and `.navigation.yml` sets each section's title and icon.

## Editing

```bash [Terminal]
npm run dev:docs    # http://localhost:3004
```

- Write Markdown with MDC components (`::note`, `::steps`, `::card-group`, `::accordion`, code blocks with file names).
- **Every page exists in both `content/en` and `content/es`** with the same path. Spanish uses neutral Latin American "tú" and the same product terms as the apps.
- Facts come from the code and from `docs/`. When they disagree, the code wins; fix the guide too.
- Never include secret values. Installation-specific IDs belong in `docs/infrastructure.md`, not here.

## Build and serving

```bash [Terminal]
npm run build:docs   # nuxt generate → apps/docs/.output/public
```

- `nitro.preset: 'static'` prerenders every page, `/llms.txt`, `/llms-full.txt`, raw Markdown under `/raw/…`, sitemaps and Open Graph images. Search runs in the browser.
- `prerender.failOnError` plus link crawling make broken internal links fail the build.
- The Worker `wildcard-docs` serves `.output/public` as static assets with `not_found_handling: "404-page"`. `public/_redirects` sends `/` to `/en`.
- Docus server features (AI assistant, MCP server) need a server runtime and are not available on this static deployment.

## Release

Workers Builds was connected on November 2, 2026. Production releases follow pushes
to `main` in the connected repository. The build root is `/`, the build command is
`npm ci && npm run typecheck:docs && npm run build:docs`, and the deploy command is
`npm run release:docs`. Preview builds are disabled and build caching is enabled.

Watch paths are `apps/docs/*`, `scripts/release-docs.mjs`, `package.json`,
`package-lock.json`, `.nvmrc`, `.npmrc` and `.gitignore`, with no exclusions.
This site extends Docus, so it does not watch `packages/ui/*`. An edit limited to
this site's content triggers docs without rebuilding the API, web, admin or
marketing site. Root dependency changes can affect all projects.

`scripts/release-docs.mjs` requires Workers Builds, the production branch, a clean
checkout and HEAD equal to the pushed source SHA; it tags the published version
with that SHA. Verify the successful build and active source version after each
release. Never publish manually.
