Wildcard is a messaging app where people talk to **AI contacts**: independent characters with their own name, portrait, personality, memory and voice. Contacts reply in private chats and in groups with other people and other contacts, remember what matters, take initiative, work on shared tasks and documents, research the web, use the person's connected tools over MCP and curate an adaptive **For you** feed.

Everything runs on Cloudflare. A single API Worker owns all data and logic; the iOS app, the web app and the admin panel are clients of that API.

## The product at a glance

::card-group
  :::card{icon="i-lucide-message-circle" title="Private chats and groups"}
  Durable replies generated by Meta's Muse Spark 1.3 inside Cloudflare Workflows, with typing presence, successive bubbles, reactions and quoted replies.
  :::

  :::card{icon="i-lucide-brain" title="Memory and personality"}
  Grounded facts in D1 with full-text search, audience-scoped memory, seventeen temperament traits and silent conversation learning.
  :::

  :::card{icon="i-lucide-image" title="Media"}
  Photos, PDFs, voice messages (transcribed, and answered with ElevenLabs voices), generated images, albums and stickers cut out with Meta SAM.
  :::

  :::card{icon="i-lucide-list-checks" title="Agentic work"}
  Tasks, persistent work, Markdown documents, web research, page monitors, schedules, mini apps and MCP connectors, all with explicit budgets.
  :::
::

## Who this documentation is for

- **Developers** joining the project who need to understand the architecture and run it locally.
- **Operators** who provision an independent installation in their own Cloudflare account.
- **Reviewers** who want to know which Cloudflare services are used and why.

## How this site relates to `docs/`

The repository keeps around fifty detailed feature guides in `docs/` (for example `docs/infrastructure.md`, `docs/chats.md` or `docs/caching.md`). They are the **source of truth**: they record every migration, verification status and rollback note. This site is a curated, navigable overview built on top of them and of the code. When you need the full detail of a feature, each page points to the guide that owns it.

::note
Paths in this documentation are relative to the repository root (for example `apps/api/src/index.ts`). The repository is private, so pages link to paths instead of GitHub URLs.
::

## Main components

| Component | Path | Runs on | Purpose |
| --- | --- | --- | --- |
| API Worker | `apps/api` | Worker `wildcard-api` | Hono API, Better Auth, all business logic, Workflows and Cron |
| Web app | `apps/web` | Worker `wildcard-web` | Nuxt 4 single-page app with a same-origin proxy to the API |
| Admin panel | `apps/admin` | Worker `wildcard-admin` | Super admin panel through a private `AdminAPI` entrypoint |
| iOS app | `apps/ios` | iPhone (iOS 27) | SwiftUI app with widgets, share and notification extensions |
| Marketing site | `apps/site` | Worker `wildcard-site` | Static landing page in English and Spanish |
| Docs site | `apps/docs` | Worker `wildcard-docs` | This documentation (Docus, static) |
| UI layer | `packages/ui` | Build time | Nuxt layer with the design system shared by web, admin and site |
| Shared code | `shared/` | Build time | TypeScript modules imported by both the API and the web app |
