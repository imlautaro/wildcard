## Folders

```text
.
├── apps/
│   ├── api/            # @wildcard/api   – Hono API Worker (wildcard-api)
│   │   ├── src/        # Routes, Workflows, Cron jobs, feature modules
│   │   ├── migrations/ # 93 hand-written D1 migrations (0001 … 0093)
│   │   ├── tests/      # Miniflare lifecycle tests
│   │   └── wrangler.jsonc
│   ├── web/            # @wildcard/web   – Nuxt 4 SPA + API proxy (wildcard-web)
│   ├── admin/          # @wildcard/admin – Super admin panel (wildcard-admin)
│   ├── site/           # @wildcard/site  – Static marketing site (wildcard-site)
│   ├── docs/           # @wildcard/docs  – This documentation (wildcard-docs)
│   └── ios/            # Xcode project: app, extensions, tests
├── packages/
│   └── ui/             # @wildcard/ui – Nuxt layer: tokens, App* components, icons
├── shared/             # TypeScript shared by the API and the web app
├── scripts/            # Release, provisioning, local setup and validation scripts
│   └── checks/         # Static SQL compilation and live evaluation scripts
├── docs/               # Detailed feature and infrastructure guides (source of truth)
├── AGENTS.md           # Working agreements
├── package.json        # Workspaces and root scripts
└── package-lock.json   # The single lockfile for every workspace
```

## Workspaces

The root `package.json` declares `apps/api`, `apps/web`, `apps/admin`, `apps/site`, `apps/docs` and `packages/ui`. All JavaScript dependencies are installed from the **root lockfile** with `npm ci`; workspaces never keep their own lockfile. Node.js 24 or later is required (`engines` and `.nvmrc`).

The iOS project is not a workspace; open `apps/ios/Wildcard.xcodeproj` in Xcode.

## Root scripts

| Script | What it does |
| --- | --- |
| `npm run dev:all` | API and web app together |
| `npm run dev` | API with `wrangler dev` on `http://localhost:8787` (no Cloudflare login, local cron) |
| `npm run dev:web` | Web app on `http://localhost:3000` (proxies to the local API) |
| `npm run dev:admin` | Admin panel on `http://localhost:3001` |
| `npm run dev:site` | Marketing site on `http://localhost:3002` |
| `npm run dev:docs` | This documentation on `http://localhost:3004` |
| `npm run typecheck` | Regenerates Worker types (`wrangler types`) and runs `tsc` for the API |
| `npm run typecheck:web` / `:admin` / `:site` / `:docs` | `nuxt prepare` plus `vue-tsc` (docs: `nuxt prepare`) |
| `npm run build` | API bundle with `wrangler deploy --dry-run` (does not publish) |
| `npm run build:web` / `:admin` | `nuxt build` into `.output/` with a generated `wrangler.json` |
| `npm run build:site` / `:docs` | `nuxt generate` into `.output/public` |
| `npm run setup` | Creates `apps/api/.dev.vars` (auth secret, API keys from `.env`) and applies local migrations. Alias: `npm run auth:setup:local` |
| `npm run db:migrate:local` | Applies pending migrations to the local D1 |
| `npm run db:migrate:remote` | Applies pending migrations to the **production** D1 (releases already do this) |
| `npm run test:lifecycle` | Lifecycle integration tests in Miniflare with fictional data |
| `npm run infra:provision` | Creates or reuses the D1 database and updates the binding |
| `npm run infra:photos` | Verifies (or with `-- --create` creates) the private R2 bucket |
| `npm run infra:ai-gateway` | Verifies (or with `-- --create` creates) the optional AI Gateway |
| `npm run release:ci` / `:web` / `:admin` / `:site` / `:docs` | Release scripts; they only run inside Workers Builds |
| `npm run preview:web` | Deploys a branch Preview of the web app |
| `npm run ios` | Opens the Xcode project |

## Scripts folder

| Script | Purpose |
| --- | --- |
| `release-worker.mjs` | API release: guards, remote D1 migrations, secret initialization, tagged deploy |
| `release-web.mjs`, `release-admin.mjs` | Deploy the Nitro-generated `.output/server/wrangler.json` |
| `release-site.mjs`, `release-docs.mjs` | Deploy the static assets Workers |
| `preview-web.mjs` | `wrangler preview` for non-production branches |
| `setup-local.mjs` | Local setup: Node.js check, owner-only `.dev.vars`, local migrations |
| `dev-api.mjs`, `dev-all.mjs` | Local API runner (derived Wrangler config and cron) and the combined API + web runner |
| `generate-vapid-keys.mjs` | Prints a new VAPID key set for Web Push |
| `provision-d1.mjs`, `provision-photos.mjs`, `provision-ai-gateway.mjs` | Idempotent resource provisioning |
| `check-locales.mjs` | Validates web and site translations (keys, placeholders, plurals, usage) |
| `export-connector-logos.mjs` | Exports MCP connector logos |
| `checks/*` | Static SQL compilation checks and live model evaluations |
