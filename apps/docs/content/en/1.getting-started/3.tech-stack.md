## Overview

| Layer | Technology |
| --- | --- |
| Runtime | Cloudflare Workers (`compatibility_date` `2026-10-26`, `nodejs_compat`) |
| API | TypeScript, Hono, Better Auth, raw D1 SQL, Cloudflare Workflows |
| Web and admin | Nuxt 4 (Vue 3, Vite, Nitro `cloudflare_module` preset), client-side rendering |
| Marketing and docs sites | Nuxt 4 static generation (`nuxt generate`), Docus for the docs |
| iOS | Swift, SwiftUI, App Intents, WidgetKit, AlarmKit, String Catalogs |
| Data | Cloudflare D1 (SQLite) with FTS5, Cloudflare R2 |
| AI | Meta Model API (Muse Spark 1.3, Muse Image, Muse Voice Transcribe, SAM 3.1), Workers AI embeddings, ElevenLabs |
| Tooling | Node.js 24+, npm workspaces, Wrangler 4, Miniflare, vue-tsc |
| CI/CD | Cloudflare Workers Builds connected to GitHub |

## iOS (`apps/ios`)

- Deployment target **iOS 27.0**; project created with Xcode 27.1.
- SwiftUI app target `Wildcard` with `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` and approachable concurrency.
- Extensions: `WildcardNotificationService`, `WildcardWidgets`, `WildcardShare`. Code shared by all of them lives in the synchronized folder `WildcardNativeShared`.
- **No Swift Package dependencies**: networking, Keychain, caching, audio and Markdown are implemented with system frameworks.

## External services

| Service | Used for | Configuration |
| --- | --- | --- |
| Meta Model API (`https://api.meta.ai/v1`) | Chat completions (`muse-spark-1.3`, `muse-spark-1.3-contributor`), Responses with `web_search`, `muse-image-1.0` image generation and edits, `muse-voice-transcribe-1.0` speech-to-text, `sam-3.1` segmentation | `META_API_KEY` (required for any model feature) |
| ElevenLabs | Contact voices (`eleven_v4` text-to-speech) | `ELEVENLABS_API_KEY` (optional) |
| Apple Push Notification service | iOS notifications and remote timers/alarms | `APNS_*` secrets (optional) |
| Web Push services | Browser notifications (VAPID, RFC 8291 encryption implemented with WebCrypto) | `VAPID_*` secrets (optional) |
| Remote MCP servers | Notion, Linear, GitHub, Stripe, Google Workspace and others, configured per account | Stored encrypted in D1 |
| Cloudflare DNS over HTTPS | Private-address guard for MCP egress | None |

| `activity.ts` | Typing, recording and researching labels |
