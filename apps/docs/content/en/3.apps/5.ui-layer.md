`packages/ui` (`@wildcard/ui`) is a **Nuxt layer**: web, admin and site add `extends: ['../../packages/ui']` and inherit its CSS, components, composables, plugins, icons and fonts. It is a customization layer over **Material 3**. Catalog: `docs/design-system.md`.

## Contents

| Part | Details |
| --- | --- |
| Tokens | Material 3 color roles seeded from `--md-primary: #045de3`, light and dark schemes, shape, motion and spacing (`app/assets/css/tokens.css`) |
| Typography | Manrope variable font (200–800), bundled in `public/fonts` and preloaded |
| Components | `AppButton`, `AppChip`, `AppEmptyState`, `AppIcon`, `AppIconButton`, `AppListGroup`, `AppListItem`, `AppLoading`, `AppMenuItem`, `AppNotice`, `AppSearchField`, `AppSegmented`, `AppSelect`, `AppSheet`, `AppSwitch`, `AppTextField`, `AppTopBar`, `InfoButton` |
| Icons | Solar linear and bold glyphs through `@nuxt/icon` in SVG mode, **bundled only** (`provider: 'none'`, no Iconify API calls). The registry is `app/utils/icons.ts` |
| Composables | `useTheme` (System/Light/Dark), `useUiStrings` (English defaults that the web app overrides with translations) |
| Plugins | Ripple effect, theme initialization (inline script to avoid a flash) |

## Cascade layers

All layer CSS lives in `@layer ui.reset, ui.tokens, ui.base, ui.components, ui.utilities`. Nuxt concatenates app CSS **before** layer CSS, so app styles stay **unlayered** and win by layering, not by order. Avoid generic class names in the layer (for example `.center`) that could collide with app styles.

## Rules

- New UI goes through `App*` components and tokens, not ad-hoc styles.
- The layer is i18n-free: copy is passed in or provided through `useUiStrings`.
- Dark mode CSS targets `:root[data-theme="dark"]`.
- Because web, admin and site all compile the layer, `packages/ui/*` is in all three Workers Builds watch paths. A change to the layer ships to all three.
