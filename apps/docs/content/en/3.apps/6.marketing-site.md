The marketing site (`@wildcard/site`, Worker `wildcard-site`) is an optional, independent landing page. Guide: [`docs/site.md`](/en/reference/site).

## How it is built

- Nuxt 4 extending the UI layer, with `@nuxtjs/i18n` (`prefix_except_default`): English at `/`, Spanish at `/es`.
- `nuxt generate` with `nitro.preset: 'static'` (explicit, so Workers Builds does not switch Nitro to a Cloudflare server preset) and `autoSubfolderIndex: false`, so `/es` is emitted as `es.html` and served without a redirect.
- Scenes (`HeroScene`, `MemoryScene`, `GroupScene`, `FeedScene` and more) animate with `useScene` beats, render their final state at build time and respect reduced motion.
- Scroll reveals initialize after client navigation, including language changes. Content stays visible if animation setup is interrupted, and scenes recover when scrolling away during a loop fade.
- Example contacts use one Cartoon style throughout the site. Only **Create anyone** uses the separate multi-style portrait set; both sets come from the real app generator.
- Portraits were generated with the real contact generator (`apps/site/scripts/generate-portraits.mjs`, which reads `META_API_KEY` from `.dev.vars`).
- Installation-specific links live in `apps/site/app/utils/site.ts`. While `repositoryPublic` is `false`, the site says the code is coming soon instead of linking to a private repository.

- The smaller-feature cards use actual generated sticker cutouts (Muse Image + SAM 3.1) and chat images/selfies from the app helpers. Regenerate with `node apps/site/scripts/generate-feature-assets.mjs`; assets are fictional and static, with no runtime inference.

## Serving

```jsonc [apps/site/wrangler.jsonc]
{
  "name": "wildcard-site",
  "assets": {
    "directory": "./.output/public",
    "html_handling": "auto-trailing-slash",
    "not_found_handling": "404-page"
  }
}
```

No script, binding, secret or migration. Releases run `npm run release:site` from Workers Builds.

## Copy rules

Keep copy aligned with the "Copy rules" in [`docs/site.md`](/en/reference/site): describe what is unique (independent contacts with memory, initiative, sharing, groups, For you, per-contact MCP, self-hosting, powered by Meta AI models) and do not position Wildcard against general assistants.
