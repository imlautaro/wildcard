`packages/ui` (`@wildcard/ui`) es una **capa de Nuxt**: web, admin y site agregan `extends: ['../../packages/ui']` y heredan su CSS, componentes, composables, plugins, íconos y fuentes. Es una capa de personalización sobre **Material 3**. Catálogo: [`docs/design-system.md`](/es/reference/design-system).

## Contenido

| Parte | Detalles |
| --- | --- |
| Tokens | Roles de color de Material 3 generados a partir de `--md-primary: #045de3`, esquemas claro y oscuro, forma, movimiento y espaciado (`app/assets/css/tokens.css`) |
| Tipografía | Fuente variable Manrope (200–800), incluida en `public/fonts` y precargada |
| Componentes | `AppButton`, `AppChip`, `AppEmptyState`, `AppIcon`, `AppIconButton`, `AppListGroup`, `AppListItem`, `AppLoading`, `AppMenuItem`, `AppNotice`, `AppSearchField`, `AppSegmented`, `AppSelect`, `AppSheet`, `AppSwitch`, `AppTextField`, `AppTopBar`, `InfoButton` |
| Íconos | Glifos Solar linear y bold a través de `@nuxt/icon` en modo SVG, **solo incluidos en el bundle** (`provider: 'none'`, sin llamadas a la API de Iconify). El registro es `app/utils/icons.ts` |
| Composables | `useTheme` (Sistema/Claro/Oscuro), `useUiStrings` (textos predeterminados en inglés que la aplicación web sobrescribe con traducciones) |
| Plugins | Efecto ripple, inicialización del tema (script inline para evitar un parpadeo) |

## Cascade layers

Todo el CSS de la capa vive en `@layer ui.reset, ui.tokens, ui.base, ui.components, ui.utilities`. Nuxt concatena el CSS de la aplicación **antes** que el CSS de la capa, así que los estilos de la aplicación quedan **sin layer** y ganan por las cascade layers, no por el orden. Evita nombres de clase genéricos en la capa (por ejemplo `.center`) que puedan chocar con los estilos de la aplicación.

## Reglas

- La UI nueva pasa por los componentes `App*` y los tokens, no por estilos ad hoc.
- La capa no tiene i18n: los textos se pasan como props o se proveen mediante `useUiStrings`.
- El CSS del modo oscuro apunta a `:root[data-theme="dark"]`.
- Como web, admin y site compilan la capa, `packages/ui/*` está en las watch paths de Workers Builds de los tres. Un cambio en la capa se despliega en los tres.
