Wildcard es una app de mensajería donde las personas hablan con **contactos con IA**: personajes independientes con su propio nombre, retrato, personalidad, memoria y voz. Los contactos responden en chats privados y en grupos con otras personas y otros contactos, recuerdan lo que importa, toman la iniciativa, trabajan en tareas y documentos compartidos, investigan en la web, usan las herramientas conectadas de la persona mediante MCP y curan un feed adaptativo **Para ti**.

Todo se ejecuta en Cloudflare. Un único Worker de API es dueño de todos los datos y de toda la lógica; la app iOS, la app web y el panel de administración son clientes de esa API.

## Para quién es esta documentación

- **Desarrolladores** que se suman al proyecto y necesitan entender la arquitectura y ejecutarlo en local.
- **Operadores** que aprovisionan una instalación independiente en su propia cuenta de Cloudflare.
- **Revisores** que quieren saber qué servicios de Cloudflare se usan y por qué.

## Cómo se relaciona este sitio con `docs/`

El repositorio mantiene unas cincuenta guías detalladas de funcionalidades en `docs/` (por ejemplo `docs/infrastructure.md`, `docs/chats.md` o `docs/caching.md`). Son la **fuente de verdad**: registran cada migración, estado de verificación y nota de rollback. Este sitio es una vista general curada y navegable construida sobre ellas y sobre el código. Cuando necesites el detalle completo de una funcionalidad, cada página indica la guía que la documenta.

::note
Las rutas en esta documentación son relativas a la raíz del repositorio (por ejemplo `apps/api/src/index.ts`). El repositorio es privado, así que las páginas enlazan rutas en lugar de URLs de GitHub.
::

## Componentes principales

| Componente | Ruta | Se ejecuta en | Propósito |
| --- | --- | --- | --- |
| Worker de API | `apps/api` | Worker `wildcard-api` | API Hono, Better Auth, toda la lógica de negocio, Workflows y Cron |
| App web | `apps/web` | Worker `wildcard-web` | Single-page app en Nuxt 4 con un proxy del mismo origen hacia la API |
| Panel de administración | `apps/admin` | Worker `wildcard-admin` | Panel de super admin mediante un entrypoint privado `AdminAPI` |
| App iOS | `apps/ios` | iPhone (iOS 27) | App SwiftUI con widgets y extensiones de compartir y de notificaciones |
| Sitio de marketing | `apps/site` | Worker `wildcard-site` | Landing page estática en inglés y español |
| Sitio de Docs | `apps/docs` | Worker `wildcard-docs` | Esta documentación (Docus, estática) |
| Capa de UI | `packages/ui` | Tiempo de compilación | Capa de Nuxt con el sistema de diseño compartido por la web, el admin y el sitio |
| Código compartido | `shared/` | Tiempo de compilación | Módulos TypeScript importados tanto por la API como por la app web |
