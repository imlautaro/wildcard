## Vista general

| Capa | Tecnología |
| --- | --- |
| Runtime | Cloudflare Workers (`compatibility_date` `2026-10-26`, `nodejs_compat`) |
| API | TypeScript, Hono, Better Auth, SQL de D1 directo, Cloudflare Workflows |
| Web y admin | Nuxt 4 (Vue 3, Vite, preset de Nitro `cloudflare_module`), renderizado del lado del cliente |
| Sitios de marketing y documentación | Generación estática de Nuxt 4 (`nuxt generate`), Docus para la documentación |
| iOS | Swift, SwiftUI, App Intents, WidgetKit, AlarmKit, String Catalogs |
| Datos | Cloudflare D1 (SQLite) con FTS5, Cloudflare R2 |
| IA | Meta Model API (Muse Spark 1.3, Muse Image, Muse Voice Transcribe, SAM 3.1), embeddings de Workers AI, ElevenLabs |
| Herramientas | Node.js 24+, npm workspaces, Wrangler 4, Miniflare, vue-tsc |
| CI/CD | Cloudflare Workers Builds conectado a GitHub |

| `hono` | 4.13.14 | Todos los routers (`app.ts`, módulos de rutas por funcionalidad), límites de body, cookies para el flujo OAuth de MCP |

| `zod` | 4.6.7 | Configurado en modo jitless (`src/lib/schema-runtime.ts`) para el SDK de MCP y Better Auth |
| `@modelcontextprotocol/sdk` | 1.32.2 | Cliente MCP remoto, transporte Streamable HTTP y OAuth |
| `@cfworker/json-schema` | 4.1.1 | Validación de los esquemas de entrada de las herramientas MCP |

| Paquete | Versión | Notas |
| --- | --- | --- |

| `vue` / `vue-router` | 3.5.44 / 5.4.0 | |

## iOS (`apps/ios`)

- Deployment target **iOS 27.0**; proyecto creado con Xcode 27.1.
- Target de app SwiftUI `Wildcard` con `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` y approachable concurrency.
- Extensiones: `WildcardNotificationService`, `WildcardWidgets`, `WildcardShare`. El código compartido por todas ellas vive en la carpeta sincronizada `WildcardNativeShared`.
- **Sin dependencias de Swift Package**: networking, Keychain, caché, audio y Markdown se implementan con frameworks del sistema.

## Servicios externos

| Servicio | Se usa para | Configuración |
| --- | --- | --- |
| Meta Model API (`https://api.meta.ai/v1`) | Chat completions (`muse-spark-1.3`, `muse-spark-1.3-contributor`), Responses con `web_search`, generación y edición de imágenes con `muse-image-1.0`, voz a texto con `muse-voice-transcribe-1.0`, segmentación con `sam-3.1` | `META_API_KEY` (obligatoria para cualquier funcionalidad de modelos) |
| ElevenLabs | Voces de los contactos (texto a voz `eleven_v4`) | `ELEVENLABS_API_KEY` (opcional) |
| Apple Push Notification service | Notificaciones de iOS y temporizadores/alarmas remotos | Secretos `APNS_*` (opcionales) |
| Servicios de Web Push | Notificaciones del navegador (VAPID, cifrado RFC 8291 implementado con WebCrypto) | Secretos `VAPID_*` (opcionales) |
| Servidores MCP remotos | Notion, Linear, GitHub, Stripe, Google Workspace y otros, configurados por cuenta | Guardados cifrados en D1 |
| DNS over HTTPS de Cloudflare | Protección contra direcciones privadas para el egreso de MCP | Ninguna |

## TypeScript compartido (`shared/`)

Lo importan por ruta relativa la API y la app web (el admin y el sitio no importan nada):

| Archivo | Propósito |
| --- | --- |
| `messageMarkdown.ts` | El único renderizador de Markdown autorizado a producir HTML para `v-html`, además de resúmenes en texto plano para vistas previas y push |
| `personality.ts` | Las definiciones de los diecisiete rasgos de temperamento |
| `onboarding.ts` | Estilos de avatar, listas de opciones y el parser de estilos personalizados |
| `contact-generation.ts` | Tipos de entrada y parser de la generación de contactos |
| `voice.ts` | Catálogo de acentos de voz |
| `activity.ts` | Etiquetas de escribiendo, grabando e investigando |
| `mojibake.ts` | Repara UTF-8 mal decodificado en la salida del modelo (solo API) |
