Las funciones se implementan en la API y se exponen en **ambos** clientes, iOS y web, con el mismo comportamiento, salvo que una limitación de la plataforma lo impida. Cada función tiene una guía detallada en `docs/` con su contrato de API, migraciones, reglas de caché, estado de verificación y notas de rollback.

## Estado de verificación

Las guías indican explícitamente qué se verificó y qué no (por ejemplo, "device behavior not verified" o "live inference pending"). Esta documentación no eleva esas afirmaciones: si una guía dice que algo no está verificado, trátalo como no verificado.
