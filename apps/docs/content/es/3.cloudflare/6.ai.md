## El binding `AI`

```jsonc [apps/api/wrangler.jsonc]
"ai": { "binding": "AI" }
```

Cumple dos funciones:

1. **Embeddings de Workers AI** para la memoria semántica opcional.
2. **Transporte por AI Gateway** para las llamadas a modelos de Meta cuando el enrutamiento está activado.

La generación de texto en sí **no** usa modelos de Workers AI: las respuestas vienen de Muse Spark 1.3 de Meta a través de la Meta Model API.

## Memoria semántica (opcional)

Con `SEMANTIC_MEMORY_ENABLED="true"`, la selección de memoria reordena los candidatos léxicos con embeddings `@cf/baai/bge-m3` (`apps/api/src/chat/semantic-memory.ts`). Los vectores se guardan en D1 (migración 0057) en lugar de Vectorize, lo que mantiene las reglas de aislamiento en SQL. El flag se distribuye como `"false"`. En local sigue llamando al servicio remoto de Workers AI.

## AI Gateway

El gateway es **solo para observabilidad**: gasto estimado de Spark y metadatos de las solicitudes en el dashboard de Cloudflare. No hay configurados fallback, caché, reintentos, registro de prompts ni guardrails.

```ts [apps/api/src/chat/meta.ts (simplified)]
if (env.AI_GATEWAY_ID) {
  // Autenticado por el binding; la clave del proveedor sigue siendo META_API_KEY.
  return env.AI.gateway(env.AI_GATEWAY_ID).run({ provider: 'custom-meta', /* … */ });
}
return fetch('https://api.meta.ai/v1/chat/completions', /* … */);
```

| Ajuste | Valor |
| --- | --- |
| Gateway | `wildcard`, autenticado |
| Proveedor personalizado | `meta`, URL base `https://api.meta.ai` |
| Logs de payload, caché, reintentos, rate limits | Desactivados por defecto; encabezados por solicitud activan logs solo de metadatos y costos personalizados |
| Estado actual | `AI_GATEWAY_ID=""` (llamadas directas) desde que producción devolvió HTTP 502 a través del gateway el 27 de octubre de 2026 |

La transcripción de voz y la investigación web siempre llaman a Meta directamente y quedan excluidas de las métricas del gateway.

### Aprovisionar el gateway

```bash [Terminal]
npm run infra:ai-gateway            # verificar
npm run infra:ai-gateway -- --create  # crear el gateway y el proveedor si faltan
```

El script usa tu login de Wrangler en memoria o un `CLOUDFLARE_API_TOKEN` explícito con permisos de lectura y edición de AI Gateway. Nunca imprime tokens, no sobrescribe un proveedor existente ni despliega. Para volver a activar el enrutamiento, define `AI_GATEWAY_ID` en `apps/api/wrangler.jsonc`, haz commit y push, y luego verifica de punta a punta una solicitud con datos ficticios.

## Uso de la Meta Model API

| Modelo | Endpoint | Se usa para |
| --- | --- | --- |
| `muse-spark-1.3` / `muse-spark-1.3-contributor` | `/v1/chat/completions` | Respuestas, herramientas, extracción de memoria, planificación, revisiones |
| Muse Spark con `web_search` | `/v1/responses` (`store: false`) | Investigación web |
| `muse-image-1.0` | `/v1/images/generations`, `/v1/images/edits` | Retratos, imágenes en chats, álbumes, arte de stickers |
| `muse-voice-transcribe-1.0` | `/v1/asr/transcribe` | Transcripción de mensajes de voz |
| `sam-3.1` | `/v1/responses` (en streaming, analizado con `@meta-sam/parser`) | Recortes de stickers |

Las completions no usan streaming, tienen un timeout de 45 segundos y un límite de respuesta de 256 KB. Cada cuenta elige **Estándar** o **Contributor** (con consentimiento explícito); los chats con conectores MCP siempre usan Estándar.
