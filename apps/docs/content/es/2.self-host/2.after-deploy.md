Tu instalación funciona solo con la API y la app web. Todo lo de esta página es opcional.

::steps{level="3"}

### Panel de administración

Crea un proyecto de Workers Builds para `wildcard-admin` con los comandos de [Workers Builds](/es/cloudflare/workers-builds#proyectos) (el workflow de GitHub Actions no lo publica). Para dar acceso de administración, inicia sesión en el origen de admin, copia tu ID de usuario de la pantalla "Not a super admin" en `WILDCARD_SUPER_ADMIN_USER_IDS` (variable de GitHub o variable de build de la API) y vuelve a publicar la API.

### Dominios propios

Define `WILDCARD_API_URL` y `WILDCARD_WEB_URL` como orígenes HTTPS sin ruta y luego asigna los dominios a los Workers `wildcard-api` y `wildcard-web` en el dashboard de Cloudflare (ese paso no está automatizado). Cuando ambas están definidas, no hace falta el subdominio `workers.dev`. Consulta [Variables de entorno](/es/getting-started/environment-variables).

### App de iPhone

Equipo de firma, bundle IDs, `WILDCARD_API_URL`, `WILDCARD_APP_GROUP`, `WILDCARD_LINK_HOST`, capacidades y clave de APNs (consulta [App de iOS](/es/apps/ios#configuración-para-tu-propia-cuenta)).

### AI Gateway

`npm run infra:ai-gateway -- --create`; luego define `AI_GATEWAY_ID` y haz push una vez verificado.

### Sitio de marketing y Docs

Crea un proyecto de Workers Builds para cada uno con los comandos de [Workers Builds](/es/cloudflare/workers-builds#proyectos). Define las URLs del sitio en `apps/site/app/utils/site.ts` y la URL de las Docs en `apps/docs/nuxt.config.ts`.
::

::warning
`WILDCARD_SUPER_ADMIN_USER_IDS` se aplica en cada release de la API. Si la eliminas o la dejas vacía, el siguiente release revoca todo el acceso de administración.
::

## Staging

No existe un entorno de staging. Una configuración de staging necesita sus propios nombres de Worker, base de datos D1, bucket de R2, nombres de Workflow, secretos, orígenes y configuración de iOS. Nunca apuntes las Previews ni staging a la base de datos de producción sin querer (las Previews web usan actualmente la API de producción por diseño).
